# Manacher Algorithm 
- 주어진 문자열 $S$ 내에서 가장 긴 팰런드롬 부분 문자열 구하기 (연속되어 있는 부분문자열 중에서만)  

팰런드롬 : 문자열을 뒤집어도 동일한 문자열인 경우

## Navie 방식  
기존 팰런트룸 방식에서는 일단 연속적인 부분 문자열 구간을 찾는 데에서 $N^2$ 이 걸림  
그리고 그 짜른 문자열이 팰런드롬인지 판단할려면 $N$   
총 $O(N^3)$ 만큼이나 걸림  

## 본 알고리즘  
문자에 대해 좌우대칭인 문자열의 중심일 때를 가정하여 확장해 나가는 완전탐색으로 진행을 하는 방법으로 접근  
앞에서부터 탐색하되, 각 문자를 "중심점" 이라 가정 했을 경우, 최대 확장 가능한 좌우대칭인 문자열을 구하는 방법  

팰런드롬 성질을 이용한 것 :  
-> 문자열 $S$ 가 팰런드롬인 경우 해당 문자열 앞 뒤에 또다른 팰런드롬 문자열을 붙여도 그 문자열은 팰런드롬 문자열이 된다
